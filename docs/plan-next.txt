PyCircuit: what to build next
================================

The parts that were missing are on the bench now: NMOS, PMOS, switch,
potentiometer, transformer, 555 timer and voltage regulator. This note
is the order for everything else that a schematic-and-simulate bench
still needs. Do one step, then the next. Do not start a later step
while an earlier one is unfinished.

Keep the exact V(s) next to whatever the simulator prints. That number
and that formula are the reason to use this bench. Do not add a PCB
layout tool.

The behavioural op-amps (LM358, TL072, NE5532, TL081, TL082 and LM324)
are flat-gain stand-ins on purpose. Real output swing and
gain-bandwidth wait until a simulator can show them.

The details of the netlist, the ngspice run and the scope are already
written in docs/cursor-prompt-netlist-sim-scope.txt. This file says
which of those to do, and what comes after them.

1. Netlist builder (done)
   File > Export Netlist writes the circuit as a SPICE netlist
   (core/netlist.py, no Qt) to a .cir file. Ground is node 0. Other
   nets are N001, N002, ... or a name such as Vcc. Open that file in
   LTspice and check it by hand. There is one exporter.

2. DC operating point (done)
   sim/runner.py runs that netlist in ngspice and reads the DC voltages
   and currents. Node names keep their spelling. A missing ground, a
   floating node, or a voltage-source loop is plain text. No plot yet.

3. DC numbers on the schematic (done)
   Simulate > DC Operating Point draws the ngspice voltages on the
   nodes and the currents on the parts. The selected point shows that
   voltage next to V(s). A node with no formula still shows the number.
   The run is a background thread. Editing the circuit clears the
   numbers. No plot yet.

4. Transient run and the oscilloscope (done)
   View > Oscilloscope. Start and Stop on that dock. A checked probe
   is a trace. Drag a probe and the trace follows it when that point
   was in the last run. The first circuit that is right is a unity-gain
   buffer, with the input and the output both on the scope. An LED
   lights when its current is above 1 mA. V(s) stays next to the DC
   number.

5. AC sweep and Bode (done)
   View > Bode. Start and Stop on that dock, tabbed with the
   oscilloscope. Magnitude is dB relative to the one AC source, and
   phase is degrees, on a log frequency axis. A checked probe is a
   curve. The hand check is a 1k / 159n low-pass: about -3 dB and
   -45 degrees at 1 kHz. V(s) stays next to the DC number.

6. FFT (done)
   View > FFT. A spectrum of the oscilloscope waveform, in its own
   dock, tabbed with the oscilloscope. The height is the peak of that
   wave. A whole number of cycles is one line. The hand check is a
   1 V, 1 kHz sine: a 1 V line at 1 kHz. The 1k / 159n low-pass is
   about 0.707 V at that line. V(s) stays next to the DC number.

7. Cursors on the plots (done)
   The oscilloscope, Bode, and FFT each have two cursors, A and B.
   Drag them. The dock shows both readings and the difference,
   B minus A. On Bode the value between two frequencies follows the
   log axis. V(s) stays next to the DC number.

8. Re-run when a value changes
   Change a resistor, a source, a pot position or a switch and the
   DC numbers and the plots update. No extra Run button for that.

9. Real op-amp limits
   Output swing and gain-bandwidth on the op-amp models, checked
   against the simulator. The flat-gain stand-ins stay available.

10. Example circuits
    A small menu: a divider, an RC, a unity-gain buffer, and one gate.
    Each one opens as a normal circuit the user can edit.

11. Undo, and copy and paste
    Undo and redo for place, move, wire, value and delete. Copy a
    selected chunk of the circuit and paste it somewhere else.
