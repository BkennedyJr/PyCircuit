PyCircuit: what to build next
================================

The parts that were missing are on the bench now: NMOS, PMOS, switch,
potentiometer, transformer, 555 timer and voltage regulator. This note
is the order for everything else that a schematic-and-simulate bench
still needs. Do one step, then the next. Do not start a later step
while an earlier one is unfinished.

Keep the exact V(s) next to whatever the simulator prints. That number
and that formula are the reason to use this bench. Do not add a PCB
layout tool.

The behavioural op-amps (LM358, TL072, NE5532, TL081, TL082 and LM324)
can be a flat-gain stand-in or a limited one (output swing and one
gain-bandwidth pole). Gain, Rin, Rout, GBW and the two headrooms are
editable; the defaults are that model's numbers. The generic op-amp
and the 741 stay fixed. The ideal V(s) rule stays next to the simulator
number. A probe box shows that formula, V(s) or I, when the circuit
has one. A diode, BJT, MOSFET and JFET can have their SPICE card
numbers typed. The boxes start at that model's numbers.

The details of the netlist, the ngspice run and the scope are already
written in docs/cursor-prompt-netlist-sim-scope.txt. This file says
which of those to do, and what comes after them.

The bench still calls the ngspice shared library for the DC operating
point, the oscilloscope, Bode and the FFT. Some machines will not run
ngspice.exe and will not load that DLL. No pip setting turns ngspice
into pure Python. The replacement is a Python solver in this project:
modified nodal analysis for resistors, sources, capacitors and
inductors, then DC, then AC and Bode, then transient. It lives with
the simulator code and does not import Qt. Keep V(s) next to its
numbers. ngspice stays until that solver covers the same runs.
The first piece is sim/dc_solver.py: DC voltages and currents for
resistors, capacitors (open), inductors (a short), DC sources,
AC sources (the offset) and current sources. The DC Operating Point
button still calls ngspice. AC, Bode and transient are not in this
solver yet. Step 12 stays undone until asked too.

Hicap is the program this bench is lining up with (Hicaphelp.pdf, K.
Bouwknegt). Its frequency sweep is already step 5. A few of its sweep
extras are not built yet: a linear frequency axis, one probe divided
by another, a polar plot, rms, average, minimum, maximum and peak to
peak on a trace, and keeping the previous trace so a change can be
compared. Its subcircuits are step 13, written up in
docs/plan-subcircuits.txt. Do not start them until asked.

Leave these Hicap pieces out. They do not fit this bench: thyristor
and 12-pulse gate control, a drawn arbitrary wave, diodes replaced by
a two-value resistor, symbols drawn as pixels, and a limit of 99
parts.

1. Netlist builder (done)
   File > Export Netlist writes the circuit as a SPICE netlist
   (core/netlist.py, no Qt) to a .cir file. Ground is node 0. Other
   nets are N001, N002, ... or a name such as Vcc. Open that file in
   LTspice and check it by hand. There is one exporter.

2. DC operating point (done)
   sim/runner.py runs that netlist in ngspice and reads the DC voltages
   and currents. Node names keep their spelling. A missing ground, a
   floating node, or a voltage-source loop is plain text. No plot yet.

3. DC numbers on the schematic (done)
   Simulate > DC Operating Point draws the ngspice voltages on the
   nodes and the currents on the parts. The selected point shows that
   voltage next to V(s). A node with no formula still shows the number.
   The run is a background thread. Editing the circuit clears the
   numbers. No plot yet.

4. Transient run and the oscilloscope (done)
   View > Oscilloscope. Start and Stop on that dock. A checked probe
   is a trace. Drag a probe and the trace follows it when that point
   was in the last run. The first circuit that is right is a unity-gain
   buffer, with the input and the output both on the scope. An LED
   lights when its current is above 1 mA. V(s) stays next to the DC
   number.

5. AC sweep and Bode (done)
   View > Bode. Start and Stop on that dock, tabbed with the
   oscilloscope. Magnitude is dB relative to the one AC source, and
   phase is degrees, on a log frequency axis. A checked probe is a
   curve. The hand check is a 1k / 159n low-pass: about -3 dB and
   -45 degrees at 1 kHz. V(s) stays next to the DC number.

6. FFT (done)
   View > FFT. A spectrum of the oscilloscope waveform, in its own
   dock, tabbed with the oscilloscope. The height is the peak of that
   wave. A whole number of cycles is one line. The hand check is a
   1 V, 1 kHz sine: a 1 V line at 1 kHz. The 1k / 159n low-pass is
   about 0.707 V at that line. V(s) stays next to the DC number.

7. Cursors on the plots (done)
   The oscilloscope, Bode, and FFT each have two cursors, A and B.
   Drag them. The dock shows both readings and the difference,
   B minus A. On Bode the value between two frequencies follows the
   log axis. V(s) stays next to the DC number.

8. Re-run when a value changes (done)
   Change a resistor, a source, a pot position or a switch and the
   DC numbers and the plots update. No extra Run button for that.
   Moving or deleting a part still clears them. A second edit while
   a run is going replaces that run. Simulate > Continuous is the
   usual choice. Simulate > Snapshot keeps one reading, and a new
   value clears it. The same choice is on the oscilloscope, Bode,
   and FFT.

9. Toolbar buttons the user can choose (done)
   The toolbar repeats the menus. It starts with Delete, Wire Mode,
   Probe Mode, and DC Operating Point, on the same row as the grid
   size. Save stays in the File menu. View > Toolbar lists every
   one of those menu commands, and each can be shown or hidden.
   The choice is remembered. Zoom is not on the toolbar: View has
   Zoom In, Zoom Out, and Zoom to Fit, with shortcuts and Ctrl plus
   the wheel.

10. Real op-amp limits (done)
    The LM358, LM324, TL072, TL081, TL082 and NE5532 have a Limits
    choice. Flat is the old stand-in. Limited holds the output
    between the rails and rolls the gain off at one pole. Gain, Rin,
    Rout, GBW and the two headrooms can be typed; a blank box keeps
    that model's number. A new part, and an old file that has no
    choice saved, stays Flat. The generic op-amp, the 741 and the
    amplifier blocks stay as they were. V(s) stays the ideal rule.
    A probe's box leads with that formula when there is one.

11. Example circuits (done)
    File > Examples opens a divider, an RC low-pass, a unity-gain
    buffer, or an AND gate. Each one is a normal circuit the user
    can edit. examples/all-features.json is still the sheet with
    every part.

12. Undo, and copy and paste
    Undo and redo for place, move, wire, value and delete. Copy a
    selected chunk of the circuit and paste it somewhere else.

13. Subcircuits made from our circuits
    A saved circuit can be opened on its own, and placed as one part
    in another circuit. Ground is the same ground everywhere. No
    nesting. The plan is docs/plan-subcircuits.txt. Do not start this
    until asked.
